## הסדר, לכל אפיון
1. דף פתיחה (`shlav-NN/01-brief-sevev-1.md`): המשחק, הכללים, המקורות, מה נכשל קודם, 8 שאלות. בלי הטיוטה של Claude. בלי פרטים אישיים, מפתחות או קוד.
2. סבב 1: אותו דף ל-ChatGPT ול-Gemini של ירון, בכרום שבמחשב שלו (Claude in Chrome), שיחה חדשה לכל אחד. Claude כותב את שלו בנפרד (02). התשובות נשמרות (03 Gemini, 04 ChatGPT).
3. סבב 2 (05): שלוש ההצעות בלי שמות (א, ב, ג); כל מודל מדרג לפי כיף, אתגר ועניין, תוקף, ובונה שלב (06, 07).
4. בדיקה: כל עובדה ומקור שלהם נבדק בטקסט המקור. מה שלא נבדק מסומן "לא נבדק".
5. סיכום לירון: מסמך Claude Docs אחד עם ההחלטות, השלב המוצע וטבלת הרעיונות. ירון בוחר.
6. אפיון: רק אחרי הבחירה, עם טבלת הכתובות. אין קוד לפני אישור (כלל 48).
