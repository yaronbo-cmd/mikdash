## שאלה 1: הנקודות היחידאיות

סימון: ✗ = נדחה (ברזל, חלק נוסף, קישוט, שעון). ? = לא בטוח.

| נקודה | Gemini ב / ג | ChatGPT ב / ג | Grok ב / ג |
|---|---|---|---|
| אבן הפינה והאבן הגדולה | מדידה במוט / מילוי מישקים בסיד | בדיקת אנך / שחרור טריזי תמיכה | פלס במוט / ניקוי וליטוש בלי ברזל |
| שערים | פירוק פיגומים / ניקוי סיד ✗ (100% "בזמן קצר") | אנך למזוזות ולמשקוף / תנועת כנפי הדלת | מילוי מישקים / פירוק פיגומים |
| יסוד המזבח | הובלת עפר ואבני מילוי / פלס ואנך | מדידת ריבוע / בדיקת נסיגת אמה | מדידה במוט / ייבוש וסיוד קל |
| הסובב | ליטוש באבן צור ? / טאטוא אבק | מדידת בליטה באמה / רציפות בפינות | ליטוש ? / ניקוי שאריות סיד |
| גוף המזבח | מישקי "גזית" ✗? / סיוד | סיוד / סיוד במקומות קשים | מישקים אנכיים / פלס אנכי |
| הכבש | משטח עץ זמני ? / ניקוי מעקה ✗ | רוחב ושיפוע / הלבנה בלי ברזל | אבני גימור ✗ / סיוד צדדים |
| ארבע הקרנות | ליטוש באבן שיוף ? / מדידה בין הקרנות | תבנית עץ / סיוד בלי ברזל | ליטוש ? / גובה אחיד במוט |
| הכיור | איטום הבסיס / ליטוש "ברזל/נחושת" ✗ | פלס / מילוי מים ומפלס | ניקוי פנים / סיוד חיצוני ? |
| פתח ההיכל | הברשת משקוף / שמן לעצי המשקוף ? | שתי דלתות חיצוניות / שתי פנימיות (מידות ד, א, לא נבדק) | יישור משקופים / פירוק פיגומים |

**הסכמה:** רמה א משלימה את המבנה. ב ו־ג הן עבודות המשך באתר: מדידה, פלס, מישקים, סיוד, ניקוי, פירוק פיגומים. כולם מסמנים "המחשה".
**הבדלים:**
- ChatGPT הכי זהיר: כמעט רק מדידה וסיוד (סיוד המזבח, לפי טענתו, יש לו מקור). הוא היחיד שנתן שמות לשערים ומקורות (לא נבדק).
- Gemini מגוון יותר, אבל עם ברזל ליד המזבח, "גזית" במזבח, מעקה לכבש, ושעון ("בזמן קצר").
- Grok פשוט ושימושי, אבל מוסיף "אבני גימור" לכבש.

שלושתם כתבו 8 עד 10 משפטים. **משותף לשלושה:** רמה א בונה את המבנה שלם ובגודלו; ב ו־ג עבודות המשך מציאותיות בלי להוסיף חלקים; "המחשה" למה שאין לו מקור; טיול לפני ב ו־ג; סימן סביב המבנה; ערימה בלי מונים; שיא ברמה ג.

## מחלוקות

1. **כמה עבודות לפני ב ולפני ג:** 1 ו־1 (ChatGPT, Grok) מול 2 ו־3 (Gemini).
2. **להישאר על עבודה אחת:** עמדת עזר סמוכה (ChatGPT) מול "הרמה מחכה, רדומה" (Gemini, Grok).
3. **איפה הערימה:** ליד כל אתר (Gemini, Grok) או מחסן מרכזי (ChatGPT).
4. **נצנוץ על המבנה עצמו:** כן (Grok) מול בלי שינוי במבנה (ChatGPT).
5. **ליטוש אבני המזבח (סובב, קרנות):** Gemini ו־Grok מציעים; ChatGPT רק מודד ומסייד.
