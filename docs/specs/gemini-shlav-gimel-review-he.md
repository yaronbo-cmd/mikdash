## 0. בשורה התחתונה

1. **הרעיון המרכזי טוב, ושלך:** שני ז׳אנרים לסירוגין — ידיים בשטח (שלב א׳), וראש בפנקס הניהול (שלב ג׳). זה עובד במשחקים אמיתיים, נותן הפוגה ועומק, ומחזיק גם ילד וגם מבוגר.
2. **"נתיב אחד, בלי לבחור 'מצב ילד' או 'מצב מבוגר'"** — ג׳מיני צדק כשענה לך כנה. עומק שכל אחד יורד אליו כמה שהוא רוצה.
3. **חמש בעיות יסוד:**
   1. **מי השחקן?** ג׳מיני הופך אותו ל"מנכ״ל-על", "אדריכל העל של ירושלים" ומנהל קופת בדק הבית. **זה סותר כלל קבוע שלך:** כהן פשוט, לא ממונה ולא אמרכל. את כספי ההקדש ניהלו "שלשה גזברין ושבעה אמרכלין" (שקלים ה, ב).
   2. **תקופה שגויה:**
      - **חירם מלך צור** — של שלמה, בית ראשון.
      - **משלחת אופיר** — גם של שלמה.
      - **בבית השני:** "לצדנים ולצרים" שקיבלו "מאכל ומשתה ושמן" (עזרא ג, ז) — וזה מקור מצוין לסחר חליפין אמיתי.
   3. **ערכים:**
      - **"שחד שיירות"** — כפתור בלוח.
      - **"חותמות קדושה וכשרות"** כסחורה שסוחרים בה ומשיגים בה "בלעדיות" על אחרים.
      - **"ציון טהרה"** כבונוס בתחרות.
      - **הלכה לא נמכרת ולא מנצחת.**
   4. **בורסה בין שחקנים, וטבלת "שחקני אמת"** — סותרות כלל קבוע שלך: "רק בעולמות פרטיים בקוד הזמנה, בלי זרים". בורסה עם היצע וביקוש צריכה המון שחקנים, כלומר זרים, ושרת, ופיקוח. ובין ילדים — סחר הוא פתח לניצול (האח הגדול "מוכר" לקטן).
   5. **הכסף:**
      - ג׳מיני הופך את "קופת בדק הבית" לארנק של השחקן — קונה, מוכר, משלם "תחזוקה" בכל מחזור.
      - **סותר את אפיון הנדבות:** שם, פרוטות הן של הכהן, ונותנים אותן.
      - **ו"תחזוקה שנגבית כל מחזור"** היא לחץ שגורם לחזור כדי שלא יירד. זה מנגנון אנרגיה בתחפושת.
4. **המפרט התכנותי (TypeScript) — לא לקחת.**
   - אנחנו לא כותבים ב-TypeScript, ואין שרת.
   - בקוד עצמו יש באגים:
     - עסקה שמעבירה כסף בלי להעביר את הסחורה מהמוכר;
     - עודפים שנמכרים לבד ב"2 מטבעות ליחידה";
     - נוסחת עומס הפוכה.
   - ושוב אותו דפוס: "Enterprise" → "Elite" → "Masterclass" — כל פעם ששאלת "בטוח?".
   - **מה כן לוקחים:** המושגים, לא את הקוד.
5. **ההצעה שלי (§3):** "ראש צוות" — אחד מאלף הכהנים, שמנהל את **הצוות שלו ואת המלאכה שלו**. לא את אוצר המקדש.
   - **"פנקס המלאכה":** מחסן ושיירות שרואים; סוחרי צור וצידון (סחר בעין, כמו בעזרא); משלוחים עם המתנה אמיתית (הוקים); ופנקס בונים משפחתי.
   - **ל-Hard Fun של מבוגרים — חמש חידות ניהול אמיתיות מהמקורות** (§3.4).

## 3. ההצעה: שלב ג׳ כ"פנקס המלאכה" של ראש צוות

### 3.1 מי השחקן
- **אותו כהן,** אחד מאלף הכהנים שלמדו סיתות ונגרות (קדמוניות טו 390). בשלב א׳ הוא **מקבל צוות** — זה כבר קיים ("לבד לא נגמור. הנה הצוות שלך.").
- **בשלב ג׳ הוא ראש הצוות:** דואג שיהיו לצוות אבנים, סיד, עצים וכלים, ושהשיירות יגיעו.
- **הוא לא מנהל את אוצר המקדש, ולא חותם בשם המלך.** הוא קונה מסוחרים, מזמין מהמחצבה, ומארגן משלוח.
- ⚠ **"ראש צוות" הוא קצת יותר מ"כהן פשוט".** הוא אחד מאלף, לא ממונה על המקדש. **הכרעה שלך.**

### 3.2 הכסף והחומרים — מתיישב עם אפיון הנדבות
- **"אוצר המלאכה" של הצוות:** שכר על עבודה שנעשתה, לפי האיכות (מהודר/כשר). "יִנָּתְנוּ לָאֻמָּנִין בִּשְׂכָרָן" (שקלים ד, ו).
- **קונים בו:** חומרים, הובלה וכלים. לא כוח — **חומר ודרך.**
- **הפרוטות האישיות** (שלב ב׳, אפיון הנדבות) נשארות כפי שהן: של הכהן, לנתינה.
- **שני מטבעות? לא:**
  - **"אוצר המלאכה"** — של הצוות, בשלב א׳ ובשלב ג׳.
  - **הפרוטות** — של הכהן, בשלב ב׳.
  - **הכרעה שלך:** לאחד, או להשאיר שניים עם תפקידים שונים.
- **"כמה אני עשיר":** רואים עושר בחומר — ערימות אבני גזית, קורות ארז שמחכות, שיירה בדרך. "האוצר של הצוות שלי מלא". **לא "אני עשיר".**

### 3.3 הפנקס — ארבעה לוחות
**עיצוב:** קודקס עור, ומבט על מפה מאוירת. **בטלפון:** לוח אחד בכל פעם, והחלקה ביניהם.

1. **מחסן ודרכים:**
   - **מה רואים:** ערימות לפי חומר; מפה — הלבנון, ים יפו, הדרך לירושלים, המחצבה, הכבשנים; שיירות זזות.
   - **בכל חומר:** כמה יש, כמה בדרך, ומתי יגיע.
   - **צוואר בקבוק** = אירוע עם מקור: הנמל עמוס; גשם בלילה (תענית כג ע"א); גלגל עגלה נשבר.
2. **סוחרים** (של המשחק, לא שחקנים):
   - **צור וצידון** — ארזים, תמורת "מאכל ומשתה ושמן" (עזרא ג, ז). סחר בעין: מרכיבים "סל" של שמן, יין וחיטה.
   - **המחצבה, הכבשנים, והנגרים.**
   - **מחירים יציבים,** שמשתנים בעונות: חורף — הים סוער והדרכים בוץ.
3. **משלוחים:**
   - **הזמנת רפסודה מהלבנון:** אורך ימים אמיתיים, עם מקור — כמו הוק הטלה.
   - **"קשר" עם סוחר:** משלוח בזמן והגעה שלמה — וההנחה הבאה גדלה.
   - **אין קנסות, אין "השהיה מחוסר כסף", אין ניקוז.**
4. **פנקס הבונים:**
   - **של הצוות שלך:** השיאים שלך בכל פעולה (שלב א׳); המהודרים; התארים — מנופאי, בנאי, בודק, נגר.
   - **של המשפחה** (עולם פרטי): מי בנה איזה חלק בבית — **כמו The Red Cathedral, בית אחד שבונים יחד.**
   - **של העולם:** אחוזון בלי שמות (אם תאשר).

### 3.4 Hard Fun למבוגרים — חמש חידות ניהול מהמקורות
1. **הים והעונות:**
   - רפסודות ארזים מהלבנון ליפו (עזרא ג, ז). בחורף הים סוער.
   - **המשימה:** לתזמן הזמנות כך שהקורות יגיעו כשהבנייה צריכה אותן — לא מוקדם מדי (המחסן מוגבל) ולא מאוחר מדי.
2. **אלף עגלות** (קדמוניות טו 390):
   - **מספר העגלות מוגבל.** מחלקים אותן בין מחצבה, עצים וסיד.
   - **אופטימיזציה** — בלי עונש: מי שמחלק טוב, האתר מתקדם מהר יותר לעין.
3. **הסיתות במחצבה:**
   - "אבן שלמה מסע נבנה" (מלכים א ו, ז) — אבן מסותתת יקרה יותר להובלה, וחוסכת עבודה בשטח.
   - **השאלה:** מה לסתת במחצבה ומה להביא גולמי.
4. **אבני המזבח מבקעת בית כרם** (מדות ג, ד):
   - רק אבנים שלמות. צריך להזמין יותר מהנחוץ, כי חלק ייפסל בבדיקה.
   - **כמה עודף להזמין?** תלוי כמה טוב אתה בבדיקה — שלב א׳.
5. **שכר והידור:**
   - **מהודר מכניס יותר לאוצר המלאכה.** אבל זמן העבודה של הצוות מוגבל.
   - **לאן לשלוח את הצוות המיומן ביותר?** לחומה (כמות) או להיכל (הידור)?

export function depositResourceFromFieldAction(
  currentState: PlayerInventoryState,
  resourceType: ResourceType,
  branchId: number,
  accuracyScore: number // ציון הדיוק של השחקן בטאץ' (0.0 עד 1.0)
): PlayerInventoryState {
  
  // קביעת דרגת האיכות בהתאם לדיוק בשטח (Hard Fun Reward)
  let tier: QualityTier = 'Regular';
  if (accuracyScore >= 0.95) {
    tier = 'Masterpiece';
  } else if (accuracyScore >= 0.80) {
    tier = 'Splendor';
  }

  // חישוב כמות וערך בהתאם לסוג המשאב והאיכות
  const baseQuantity = 10;
  const multiplier = tier === 'Masterpiece' ? 2.5 : tier === 'Splendor' ? 1.5 : 1.0;
  const finalQty = Math.round(baseQuantity * multiplier);

  // עדכון המלאי
  const updatedItems = { ...currentState.items };
  updatedItems[resourceType].total += finalQty;
  updatedItems[resourceType].byTier[tier] += finalQty;

  return {
    ...currentState,
    items: updatedItems
  };
}

export function executeAtomicTrade(
  listing: TradeListing,
  buyerInventoryState: { playerId: string; coins: number; addItemsFn: (item: MarketItemOffer) => boolean },
  sellerState: { coins: number }
): TransactionResult {
  
  if (listing.status !== 'ACTIVE') {
    return { success: false, errorCode: 'NOT_FOUND' };
  }

  if (Date.now() > listing.expiresAt) {
    listing.status = 'EXPIRED';
    return { success: false, errorCode: 'EXPIRED' };
  }

  // בדיקת מטבעות אם מדובר בעסקת רכישה
  if (listing.priceInCoins) {
    if (buyerInventoryState.coins < listing.priceInCoins) {
      return { success: false, errorCode: 'INSUFFICIENT_FUNDS' };
    }
  }

  // ניסיון הוספת הפריט למלאי הקונה
  const itemAdded = buyerInventoryState.addItemsFn(listing.offeredItem);
  if (!itemAdded) {
    return { success: false, errorCode: 'INVENTORY_LOCKED' }; // מחסן הקונה מלא
  }

  // ביצוע העברה פיננסית אטומית
  if (listing.priceInCoins) {
    buyerInventoryState.coins -= listing.priceInCoins;
    sellerState.coins += listing.priceInCoins;
  }

  listing.status = 'FULFILLED';

  return {
    success: true,
    updatedState: {
      buyerCoins: buyerInventoryState.coins,
      sellerCoins: sellerState.coins,
      tradeLogEntry: {
        transactionId: `tx_${Date.now()}`,
        timestamp: Date.now(),
        resourceType: listing.offeredItem.resourceType,
        tier: listing.offeredItem.tier,
        quantity: listing.offeredItem.quantity,
        finalUnitPrice: listing.priceInCoins ? listing.priceInCoins / listing.offeredItem.quantity : 0,
        channel: listing.channel
      }
    }
  };
}

export function processDiplomacyCycle(
  activeContracts: DiplomaticContract[],
  currentTreasuryCoins: number
): DiplomacyTickResult {
  const updatedContracts: DiplomaticContract[] = [];
  const resourcesToAdd: ContractYieldItem[] = [];
  const suspensionEvents: { contractId: string; reason: string }[] = [];
  let totalCoinsDeducted = 0;

  for (const contract of activeContracts) {
    if (contract.status !== 'ACTIVE') {
      updatedContracts.push(contract);
      continue;
    }

    // בדיקה האם לקופת בדק הבית יש מספיק מטבעות לתשלום התחזוקה השוטפת
    const currentFunds = currentTreasuryCoins - totalCoinsDeducted;
    
    if (currentFunds < contract.upkeepCostCoinsPerCycle) {
      // חוקי ברזל: אין Game Over! החוזה מושהה (Suspended) עד להתאוששות הקופה
      updatedContracts.push({
        ...contract,
        status: 'SUSPENDED_LOW_FUNDS'
      });
      suspensionEvents.push({
        contractId: contract.contractId,
        reason: 'החוזה הושהה זמנית עקב מחסור במטבעות בקופת בדק הבית. ניתן לחדש בלחיצה!'
      });
      continue;
    }

    // גביית עלות תחזוקה והוספת תשומות למחסן
    totalCoinsDeducted += contract.upkeepCostCoinsPerCycle;
    resourcesToAdd.push(contract.yieldOutput);

    const nextRemainingCycles = contract.remainingCycles - 1;
    const isCompleted = nextRemainingCycles <= 0;

    updatedContracts.push({
      ...contract,
      remainingCycles: Math.max(0, nextRemainingCycles),
      status: isCompleted ? 'COMPLETED' : 'ACTIVE'
    });
  }

  return {
    updatedContracts,
    resourcesToAdd,
    coinsDeducted: totalCoinsDeducted,
    suspensionEvents
  };
}

export function calculatePlayerPrestige(breakdown: PlayerScoreBreakdown): number {
  const { splendorScore, efficiencyScore, communityBarterScore } = breakdown;
  
  const weightedSum = 
    (splendorScore * 0.45) + 
    (efficiencyScore * 0.35) + 
    (communityBarterScore * 0.20);

  return Math.round(weightedSum * 10) / 10;
}

export function evaluatePrestigeTitles(breakdown: PlayerScoreBreakdown): PrestigeTitleId[] {
  const titles: PrestigeTitleId[] = [];

  if (breakdown.splendorScore >= 90 && breakdown.efficiencyScore >= 85) titles.push('MASTER_MASON');

  return titles;
}
