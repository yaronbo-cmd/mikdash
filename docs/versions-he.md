## נוהל לכל בנייה חדשה
1. בונים כרגיל על ענף העבודה, ו־`index.html` בשורש הוא הבנייה החדשה (הכותרת "בנייה NN — …").
2. דוחפים גם ענף בשם הבנייה, מאותו קומיט: `git push origin HEAD:refs/heads/build-NN`
3. מפעילים את הפרסום: workflow ‏"Deploy to GitHub Pages" → Run workflow על `main` (או מחכים עד שעה, ההרצה השעתית תפרסם).
4. נותנים לירון את הקישור `https://yaronbo-cmd.github.io/mikdash/v/NN/`.
- תיקון לאותה בנייה: אפשר לדחוף שוב לאותו `build-NN`. בנייה חדשה = מספר חדש = ענף חדש.
- לא מוחקים ענפי `build-*`.

## איך זה עובד
`.github/workflows/pages.yml` רץ על `main` (דחיפה ל־main, הפעלה ידנית, וכל שעה). הוא מושך את כל ענפי `build-*`,
ו־`.github/versions/build_site.py` מרכיב את האתר: עץ `main` בשורש, ו־`index.html` של כל ענף ב־`v/NN/`.
ההרצה השעתית מפרסמת רק אם ענף נוסף או זז (משווה ל־`v/heads.txt` באתר).
דחיפה לענף `build-*` לא מפעילה פרסום בעצמה, כי סביבת ה־Pages מפרסמת רק מ־`main`.

גודל: כל גרסה כ־6MB; Pages מגביל אתר ל־1GB, כלומר בערך 150 גרסאות. כשנתקרב, נוציא מהאתר (לא מ־git) גרסאות ישנות שלא צריך.
